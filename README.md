# 보존식 기록표

도봉구 어린이급식관리지원센터의 보존식 기록·관리 웹 애플리케이션입니다.
보존식 채취일, 폐기일, 식단 내용을 기록하고 엑셀 다운로드 및 인쇄 출력을 지원합니다.

## 주요 기능

- **기록 관리** : 낮(오전간식·점심·오후간식) / 석식 구분 입력
- **자동 계산** : 폐기일은 채취일 기준 +7일(09:00)로 자동 산정
- **조회 필터** : 당일 / 일주일 / 한달 / 3달 빠른 필터
- **엑셀 다운로드** : 현재 조회 결과를 `.xlsx` 파일로 저장
- **인쇄 출력** : 선택 항목(또는 전체)을 보존식 기록표 양식 카드로 인쇄
- **반응형 UI** : 데스크탑 테이블 뷰 + 모바일 카드 리스트
- **PWA** : 홈 화면 추가 후 오프라인에서도 앱처럼 사용 가능
- **커스텀 인증** : 자체 users 테이블 기반 로그인 / 계정 생성

## 기술 스택

| 분류 | 사용 기술 |
|------|-----------|
| 프레임워크 | React 18, Vite 5 |
| 백엔드 / DB | Supabase (PostgreSQL) |
| 엑셀 생성 | ExcelJS |
| PWA | vite-plugin-pwa (Workbox) |
| 배포 | Vercel |

## 프로젝트 구조

```
src/
├── App.jsx              # 루트 컴포넌트 (인증 상태 관리)
├── pages/
│   ├── Login.jsx        # 로그인 / 계정 만들기
│   └── Dashboard.jsx    # 기록 목록, 필터, 엑셀/인쇄, 인쇄용 카드 렌더링
├── components/
│   └── RecordForm.jsx   # 기록 추가 / 수정 모달
└── lib/
    ├── supabase.js      # Supabase 클라이언트
    └── auth.js          # 세션 저장·불러오기, 비밀번호 해싱
supabase/
└── schema.sql           # DB 스키마 (users, records 테이블)
```

## 로컬 개발

```bash
# 의존성 설치
npm install

# 환경 변수 설정 (.env 파일 생성)
VITE_SUPABASE_URL=https://<project>.supabase.co
VITE_SUPABASE_ANON_KEY=<anon-key>

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build
```

## DB 초기화

Supabase 프로젝트의 SQL Editor에서 `supabase/schema.sql`을 실행합니다.

```sql
-- 사용자 테이블 및 기록 테이블 생성
-- RLS 비활성화 (내부 시스템 전용)
```

계정은 웹 앱의 **계정 만들기** 탭에서 생성하거나, SQL로 직접 삽입할 수 있습니다.
비밀번호는 `SHA-256("foodlog:" + 비밀번호)` 해시로 저장됩니다.

## 보존식 규정

- 채취 시간 : 낮 **11:00**, 석식 **16:00**
- 보관 조건 : **-18℃ 이하, 144시간(6일)** 보관
- 폐기일 : 채취일로부터 **+7일 09:00** 자동 산정
